# Layer launch kit

Exactly two ImageGen calls were used: the GitHub banner and video invitation concept. All other images were produced in code using your supplied circular logo and existing generated wordmark.

## Main files
- 01-github-banner.png — 1600 × 640; repository README header.
- 02-video-invitation.png — 1920 × 1080; "Meet Layer / Make it yours / Try Layer" card for the Layer segment in your general YouTube video. The generated concept had an overlap, so its final layout was rebuilt in code with your exact logo. Add your real product/repository URL to the video description.
- 03-social-preview.png — 1200 × 630; link preview / horizontal social card.
- 04-square-promo.png — 1080 × 1080; square promotional card.
- 05-desktop-wallpaper.png — 2560 × 1440.
- 06-profile-avatar.png — 512 × 512; transparent outside the circle.
- 07-app-icon.png — 512 × 512; opaque square icon.
- 08-transparent-lockup.png — original logo + wordmark with background removed in code.
- 09-transparent-lockup-light.png — light wordmark for dark backgrounds.
- 10-video-lower-third.png — 960 × 240; title plate, transparent corners.
- 11-video-cta-overlay.png — 960 × 240; invitation overlay, transparent corners.
- 12-palette-card.png — 1200 × 720; reusable color reference.
- icons/ — PNG sizes 16, 32, 48, 64, 128, 180, 192, 256, 512.

These are raster PNGs, not vectors. Resizing the supplied logo to larger sizes cannot add original detail. The tiny icons retain the existing mark and may show less cursor detail at 16 px. The original project files were read only.

## Colors
Graphite #202329 · Dusty rose #C88DAB · Warm ivory #F6F3EE · Soft rose #E6D9E1

The logo's original lettering is retained. Additional text is rendered with locally available Segoe UI / Segoe UI Bold; font files are not bundled.

## Image generation briefs
1. Wide GitHub banner: preserve the supplied identity and palette; Layer wordmark plus "A visual website editor" on ivory, with precise rose/graphite frame-and-cursor geometry to the right; no fake UI or invented metrics.
2. Video invitation: graphite 16:9 card, existing logo in an ivory circle, "Meet Layer. Make it yours.", "Try Layer", "Link in description"; restrained rose frames. Code cleanup removed duplicated generated geometry.

See manifest.json for file-by-file dimensions and provenance.
