# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: React + TypeScript + Vite, with a local-first document model and optional server adapters so the manual editor remains useful without accounts or API keys.

## Users

People who want to design and prototype polished websites but find professional design tools overwhelming. They need a visual editor that explains common choices while still allowing precise control, and they need to hand the resulting design to another AI or developer.

## Product Purpose

Layer is an approachable visual website design and prototyping editor inspired by Figma. It lets users build multi-page website layouts, define responsive behavior and prototype interactions, inspect the result, and export a complete implementation handoff. Success means a user can create a credible prototype without an AI account, recover their work after a refresh, and produce a structured package another person or AI can implement.

## Positioning

Layer keeps one coherent document model across manual editing, preview, Layer AI, persistence, and export. The approachable surface exposes high-value controls first while retaining precise layout and behavior controls in Advanced sections.

## Operating Context

Users work in a browser-like desktop editor with page navigation, a layer hierarchy, a canvas, property panels, assets, interactions, integrations, and a compact AI assistant. Designed websites remain prototypes until exported. A short, skippable hands-on tutorial introduces the editor through a few real actions.

## Capabilities and Constraints

- Multi-page projects with reusable components, assets, styles, interactions, notes, snapshots, and a runnable prototype preview.
- Local-first persistence is the default; provider credentials never enter project exports or public bundles.
- Manual editing must work without an AI account or API key.
- Initial integrations cover Google Fonts and an icon catalog, with persistent install/enable state and source/license metadata.
- AI providers include OpenRouter, NVIDIA NIM, Anthropic/Claude, OpenAI/GPT, and custom OpenAI-compatible endpoints, using adapters and secure request paths when configured.
- Optional vision-model routing and OCR are surfaced as capabilities with honest unavailable states when not configured.
- Accessibility, reduced motion, keyboard navigation, and clear recovery paths are required.
- No commercial claims, fabricated credentials, or fake live-service results.

## Brand Commitments

The product is named Layer. The integrated assistant is named Layer AI, with “Ask Layer” used for contextual actions. Avoid hype and slogan-like marketing copy; controls should describe the action they perform.

## Evidence on Hand

No pre-existing product implementation or brand assets were found in the target project. The requested product brief is the source of truth. External live credentials are not assumed.

## Product Principles

1. Make the common path understandable before exposing advanced precision.
2. Keep the document model honest and shared across every surface.
3. Make prototype behavior explicit rather than implying production connectivity.
4. Treat recovery, export, and handoff as first-class editing tasks.
5. Prefer structured, inspectable state over magic UI effects.

## Accessibility & Inclusion

The web app should support keyboard navigation, visible focus, semantic labels, readable contrast, reduced-motion preferences, narrow windows, and checks for missing text alternatives, poor contrast, overflow, and undersized interactive targets.
