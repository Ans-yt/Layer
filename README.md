# Layer

Layer is a local-first visual website design and prototyping editor. It keeps pages, layers, responsive rules, components, interactions, assets, notes, AI context, and export data in one inspectable document.

The editor works without an AI account. Layer AI uses the local editor command path when no provider is connected, and uses the secure local service for configured providers.

## Run it

Requirements: Node.js 22+ (Node 25 also works in this workspace) and npm.

```powershell
cd C:\Users\Administrateur\Documents\GitHub\Layer
npm install
npm run build
npm start
```

Open **http://127.0.0.1:8787/**.

For frontend iteration with the secure service running in another terminal:

```powershell
# terminal 1
npm start

# terminal 2
npm run dev
```

The Vite dev server is normally **http://127.0.0.1:4173/** and proxies `/api` to port 8787. If another process owns that port, Vite selects the next available port.

## Optional service configuration

Copy `.env.example` into your shell environment. The Node service reads:

- `PORT` or `LAYER_PORT` — default `8787`.
- `LAYER_HOST` — default `127.0.0.1`.
- `LAYER_DATA_DIR` — encrypted service data location; default `.layer-data`.
- `LAYER_ALLOWED_ORIGINS` — comma-separated non-loopback browser origins.
- `LAYER_ALLOW_LOCALHOST_MCP=true` — explicitly allow HTTP localhost MCP endpoints for development.
- `LAYER_SECRET_KEY` — optional 32-byte hex/base64 key. If omitted, a random key is created at `.layer-data/master.key`.

Provider credentials and MCP bearer tokens are entered through **Connections** and encrypted by the Node service. They are not written to the project file, exported package, client bundle, or logs.

## Core workflows

- **Pages and layers:** use the left rail, Layers list, canvas selection, direct manipulation, Inspector fields, and page setup.
- **Snapping:** blue dotted guides support edges, centers, parent relationships, grids, user-guide hooks, baselines, equal gaps, and matching-size resize candidates. Hold Alt while dragging to bypass snapping.
- **Gestures:** Shift-click multi-selects; left-drag selects a region; right-click opens the context menu; right-drag selects without opening it; Ctrl/⌘ + right-click toggles a target.
- **Preview:** Preview uses the saved interaction definitions. Use the viewport picker for desktop, tablet, phone, or a wide arbitrary viewport.
- **Layer AI:** attach the selection, page, or project. With no provider, supported local editing commands are proposed and remain undoable. With a connected provider, validated structured operations are proposed before applying unless automatic apply is enabled.
- **Connections:** configure OpenRouter, NVIDIA NIM, Anthropic, OpenAI, or custom OpenAI-compatible providers. Model discovery is live where supported; manual model IDs remain available. MCP is streamable HTTP only; local stdio needs a reachable bridge.
- **Assets:** the Assets panel includes starter sections, patterns, live Iconify/Google Fonts catalogs, installed catalog state, local uploads, reusable components, design tokens, and marketplace metadata.
- **Review:** checks cover resolved overflow, contrast limits, missing alt text, interactive target size, native text copy, snapshots, OCR, and handoff export.
- **Export:** export a `.layer.zip` package containing validated `design.layer.json`, brief, schema, assets/manifest, licenses, screenshots when attached, and a runnable `preview/index.html` with its preview runtime when the app was built.

## Tests

```powershell
npm test
npm run test:server
# requires the local service on 127.0.0.1:8787
npm run test:e2e
```

The browser workflow uses isolated Chromium. It exercises selection, duplication, right-drag, Layer AI local proposal/apply, connections, review findings, preview navigation, export download, refresh recovery, the tutorial, and narrow-window behavior.

## Known boundaries

- No provider credentials or live third-party provider calls were assumed in this workspace. Adapter fixtures and local failure paths are tested; a live provider is only verified after a user configures one.
- Video inspection is reported accurately as unsupported unless the selected endpoint has an adapter; sampled still frames are labeled as sampled frames.
- OCR is optional and downloads language data from the Tesseract.js CDN when enabled.
- The Node service intentionally does not run local stdio MCP processes. Use a remote streamable HTTP endpoint or a separately managed bridge.
- The preview runtime is generated by `npm run build`; do not open an old ZIP and infer current app behavior from it.
